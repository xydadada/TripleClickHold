# 三倍点击保持器

这是与原侧键连点器分开的独立程序。

当前版本 1.1.0。首次启动会打开设置窗口，也可以从托盘菜单选择“设置…”。设置保存在 `%LocalAppData%\TripleClickHold\settings.json`，与旧版完全分开。

切换开关时会在鼠标附近显示约 1 秒的“连点：已开启/已关闭”提示。提示窗口不激活、不接收鼠标点击，不会改变游戏焦点。

设置窗口可调整每次按下输出的点击次数（1–20）、模拟事件间隔（固定值或在最小–最大范围内逐次随机，0–100 毫秒）、是否在长按时保持最后一次按下、左键/右键是否启用、切换热键、退出热键、启动时是否启用以及托盘状态提示。长按保持最后一次按下，是为了保证短按恰好输出 N 次、长按仍保持按住。

- F8：开启/关闭
- Ctrl+Alt+F11：完全退出
- 鼠标侧键 Mouse4 / Mouse5：按下任意一个开启/关闭（侧键为专用切换键，不执行浏览器前进/后退）
- 启动默认关闭

开启后，左键和右键都按以下方式工作：前两次点击完整执行，第三次按下会保持到物理按键松开。因此快速点击一次相当于三次，长按时第三次按下仍保持。

程序要求管理员权限，以便与管理员权限运行的游戏处于同一输入权限级别。不要同时启用两个会拦截左右键的连点器。
