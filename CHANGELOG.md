# Changelog

## 1.1.0 - 2026-08-31

- Added a visible settings window with persistent configuration.
- Added fixed or random per-event delay ranges.
- Added configurable click count, buttons, hold behavior, hotkeys, startup state, and tray status.
- Added Mouse4/Mouse5 side-button toggle support.
- Added a non-activating status overlay near the cursor.
- Cancelled unfinished click sequences when a newer physical press arrives.
- Added offline self-checks, icon assets, and a Windows publish workflow.
